# Connected graph catalogue: n = 8

`n8.g6` is the complete catalogue of 11,117 connected, simple, pairwise
non-isomorphic graphs on eight vertices, encoded as one graph6 record per line.

- Source: Brendan McKay, ANU Combinatorial Data catalogue
- URL: https://users.cecs.anu.edu.au/~bdm/data/graph8c.g6
- Catalogue page: https://users.cecs.anu.edu.au/~bdm/data/graphs.html
- Downloaded: 2026-10-29
- Expected records: 11,117
- SHA-256: `0002354f1ab3344a2706626a037ad15367bf23a2163aa68f552c3a169ca9a036`
- Format: graph6
- Licence: the McKay data collection states that, except where otherwise
  indicated, its data files are available under CC BY 4.0.

The application validates count, unique graph6 records, order, simplicity, and
connectedness before using this offline dataset. It does not repeat pairwise
isomorphism checks over the catalogue.
