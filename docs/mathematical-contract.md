# Mathematical contract

For a selected invariant family, Invariant Twins searches connected simple
graphs of equal order for non-isomorphic pairs with equal fingerprints. A
reported witness is ordered by the finite search domain's stated rules.

Every absence or collision result is a finite computational result for the
enumerated graph family. It is not a theorem about arbitrary graph order.

The application keeps graph6 witnesses, exact integer polynomial coefficients,
and NetworkX isomorphism checks so that reported finite results are
reproducible.
